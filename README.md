# PaweesRaag — Portfolio

A static portfolio for my learning and work around cybersecurity, reverse engineering, and low-level systems.

## Run locally

No build step or package installation is required. Open `index.html` in a browser.

## Deploy

The site is designed for GitHub Pages. The workflow in `.github/workflows/pages.yml` publishes the repository contents whenever changes are pushed to `main`.

In the repository settings, open **Pages** and set the build and deployment source to **GitHub Actions**. The workflow will then deploy the site.

## Content notes

Project areas on the page currently describe ongoing learning tracks, not claimed professional experience or completed deliverables. Replace their links and descriptions as specific repositories and write-ups become ready.
